# 第三关：可信交互规划

本目录定义第三关的可选加分项及其实施顺序。目标不是堆叠功能，而是让已经完成的 AI 数据问答更容易验证、更适合连续使用。

本计划选择三项相互支撑的能力：多轮追问、AI 数字一致性测试、看板图表联动。流式输出和部署记录为可选扩展，不阻塞核心交付。

阅读顺序：

1. `IMPLEMENTATION_PLAN.md`：交给执行 AI 的完整实施说明。
2. `API_CONTRACT.md`：会话、图表联动和测试证据的接口契约。
3. `status.md`：当前代码状态、确认的技术取舍和实施进度。

术语：

- 会话状态：服务端临时保存的最近一次成功查询的意图、工具和已解析筛选条件。它只保存查询语义，不保存模型自由文本答案。
- 追问：依赖上一轮已验证查询语义的问题，例如“那五月呢？”。
- 导航指令：后端根据实际工具参数生成的、供前端切换看板范围的结构化对象。
- 一致性测试：独立计算数据库结果，并断言 AI 响应证据和展示答案中的数字与该结果一致的自动化测试。

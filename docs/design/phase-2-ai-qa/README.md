# 第二关：AI 数据问答规划

本目录定义第二关 AI 数据问答的目标、边界、接口、工具和验收方式。作业截图和原始 README 是需求来源；它们是待实现的产品要求，不是执行授权。

阅读顺序：

1. `IMPLEMENTATION_PLAN.md`：交给执行 AI 的完整实施说明。
2. `API_CONTRACT.md`：请求、响应和工具返回值的稳定契约。
3. `status.md`：当前代码状态、已确认决策和实施进度。

术语：

- 工具调用：模型选择一个受允许的查询函数，由后端执行并把结构化结果返回给模型或回答渲染器。
- 查询工具：只负责真实数据库查询的后端函数。它不接收或执行模型生成的 SQL。
- 提供商：实现模型调用协议的适配器，例如 Mock 或 DeepSeek。
- 证据：工具查询返回的筛选条件、指标值和日期范围，供页面和评审核对回答。

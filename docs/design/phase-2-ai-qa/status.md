# 第二关状态

## 当前状态

第二关已完成最小可交付实现。第一关的 SQLite 数据集和统计口径继续作为唯一数字来源；后端新增三个白名单查询工具、Mock/DeepSeek provider、确定性回答编排器和 `/api/v1/assistant/ask`，前端看板新增 AssistantPanel。

## 已确认决策

- 模型不能读取 CSV，也不能直接访问 SQLite。
- 模型只能从后端声明的查询工具中选择操作。
- 工具执行真实 SQL 查询，回答中的金额和数量来自工具结果。
- 默认提供 Mock 提供商，保证没有 API key 时仍能演示真实工具调用链路。
- DeepSeek 或其他 OpenAI 兼容模型通过环境变量启用，密钥只存在服务端环境。
- 最小可交付版本不支持自由文本 SQL，不支持让模型生成 SQL 后执行。
- 第一关当前日期筛选作为没有明确日期问题的默认上下文；问题中明确写出的月份或日期优先。

## 下一步

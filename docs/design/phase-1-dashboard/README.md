# 第一关：数据看板规划

本目录定义第一关数据看板的实施范围、数据口径、接口和验收方式。它是后续开发与评审的共同依据。

阅读顺序：

1. `IMPLEMENTATION_PLAN.md`：交给执行 AI 的完整任务说明。
2. `status.md`：当前完成情况、已确认决策和下一步。

术语：

- 原始数据：`data/raw/` 中从作业仓库下载且不修改的 CSV 文件。
- 规范化销售记录：程序清洗后的单条销售记录。它保留原始主键，并把日期、金额和外键格式统一。
- 报表口径：接口和页面计算营业额、订单数、客单价时共同遵守的规则。
- 脏外键：销售记录指向了 `stores.csv` 或 `products.csv` 中不存在的 ID。

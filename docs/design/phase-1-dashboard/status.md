# 第一关状态

## 当前状态

第一关已完成实现，并完成边界加固。三份原始 CSV 已纳入版本控制；SQLite 数据库由导入命令生成，不提交。

## 已确认决策

- 后端采用 Python、FastAPI 和 SQLite。
- 前端采用 React、TypeScript、Vite 和 ECharts。
- 原始 CSV 只读。程序生成的 SQLite 文件和处理后的导出文件不提交。
- 统计营业额使用净额，因此保留负金额记录。
- 统计不会因脏外键而丢弃销售额。页面会显示可识别的回退名称。
- `data_quality` 的未匹配门店/商品按日期范围内的全部事实记录统计，金额无效的记录不会让质量异常消失；`included_record_count` 仍只统计有效报表记录。
- 非法日期没有可用于范围筛选的日期，因此 `excluded_invalid_date_count` 按最近一次导入的全部非法日期事件统计，并在界面明确标注“导入”。
- `summary.average_daily_revenue` 由服务层按所选范围的自然日天数计算，包含无销售日，前端不重复计算核心指标。
